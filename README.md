# Model-Based Design Bootcamp

Bine ai venit la Model-Based Design Summer School!
 
Acest repository contine toate materialele utilizate pe parcursul scolii de vara: prezentari, exemple, exercitii, proiecte si resurse suplimentare care te vor ajuta sa intelegi si sa aplici conceptele de Model-Based Design in sisteme embedded si aplicatii automotive.

Materialele sunt organizate pe zile. In fiecare folder vei gasi resursele necesare pentru sesiunile respective.

Mult succes si spor la explorat!
